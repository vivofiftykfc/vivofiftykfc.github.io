Information Theory, Chapter 6: The Noisy-Channel Coding Theorem

1. Error Probability and Decoding Rules

1.1 Factors affecting error probability

  • The error probability ($P_E$) depends both on the statistical properties of the channel and on the chosen decoding rule.

1.2 Definition of a decoding rule

  • For a discrete single-symbol channel, let the input alphabet be $A={a_i}$ and the output alphabet be $B={b_j}$.

  • A decoding rule is a function $F(b_j) = a_i$ that, for every received output symbol $b_j$, assigns one unique input symbol $a_i$.

1.3 Average probability of error

  • Once the decoding rule $F(b_j)=a_i$ has been fixed, the average error probability $P_E$ is the mean of the conditional error probability $P(e|b_j)$ over the output space $Y$:

    $$
    P_{E} = \sum_{j=1}^{s} P(b_j) P(e|b_j) = \sum_{j=1}^{s} P(b_j) (1 - P(a_i|b_j))
    $$

    Here, $P(e|b_j) = 1 - P(a_i|b_j)$ is the conditional error probability.

1.4 Minimum-error decoding, or MAP

  • Criterion: select a decoding function $F(b_j) = a_i^*$ that minimizes the average error probability $P_E$.

  • Implementation: for each received symbol $b_j$, find the greatest posterior probability $P(a_i|b_j)$ and decode the observation as the corresponding input symbol $a_i^*$.

    $$
    F(b_j) = a_i^* \quad \text{要求} \quad P(a_i^|b_j) \ge P(a_k|b_j) \quad \text{对所有 } a_k \ne a_i^
    $$

1.5 Maximum-likelihood decoding, or ML

  • When the prior probabilities $P(a_i)$ of the input symbols are all equal, the minimum-error criterion is equivalent to maximum-likelihood decoding.

  • Criterion: for every received symbol $b_j$, maximize the transition probability $P(b_j|a_i)$ and decode the observation as the corresponding input symbol $a_i^*$.

    $$
    F(b_j) = a_i^* \quad \text{要求} \quad P(b_j|a_i^) \ge P(b_j|a_k) \quad \text{对所有 } a_k \ne a_i^
    $$

  • Note: the ML criterion itself does not depend on prior probabilities, but it is guaranteed to minimize $P_E$ only when the inputs are equiprobable.

2. Error Probability and Coding Methods

2.1 Purpose of coding

  • Choosing a decoding rule cannot eliminate errors. Channel coding is introduced to reduce their probability and improve reliability.

2.2 The conflict between coding and information rate

  • A common method of channel coding is repetition, as in an $n$-fold extension of the channel.

  • The information transmission rate $R$ is:

    $$
    R = \frac{\log_2 M}{n} \quad \text{(bit/码符号)}
    $$

    Here, $M$ is the number of messages and $n$ is the code length.

  • The conflict: increasing the code length $n$ can reduce the error probability $P_E$, but it also lowers the information rate $R$.

2.3 Hamming distance and minimum-distance decoding

  • The Hamming distance $D(\alpha_i, \beta_j)$ is the number of positions at which two equal-length sequences $\alpha_i$ and $\beta_j$ contain different symbols.

  • The minimum distance $d_{\min}$ is the smallest Hamming distance between any two distinct codewords in the code:

    $$
    d_{\min} = \min_{i \ne j} {D(\alpha_i, \alpha_j)}
    $$

  • Conclusion: the larger $d_{\min}$ is, the stronger the code’s error-correcting ability, and the smaller the average error probability $P_E$ becomes.

  • Minimum-distance decoding: in a binary symmetric channel (BSC), maximum-likelihood decoding is equivalent to minimum-distance decoding:

    Upon receiving the sequence $\beta_j$, decode it as the codeword $\alpha^*$ with the smallest Hamming distance from it.

  • Selecting a code: when $M$ and $n$ remain fixed, and hence $R$ is fixed, choose the coding method that makes $d_{\min}$ as large as possible and thereby minimizes $P_E$.

3. The Noisy-Channel Coding Theorem: Shannon’s Second Theorem

3.1 Statement

Consider a discrete memoryless channel with capacity $C$.

  1. Achievability, or the coding theorem:

    When the information rate $R \le C$, a sufficiently large code length $n$ always makes it possible to find a set of codewords ($M=2^{nR}$) and a corresponding decoding rule whose average error probability $P_E$ is arbitrarily small, so that $P_E \approx 0$.

  2. The converse:

    When $R > C$, no code—however large $n$ becomes—can make the decoding error probability $P_E$ at the channel output arbitrarily small.

3.2 Meaning

  • The channel capacity $C$ is the maximum information rate at which effectively error-free transmission can be achieved through a noisy channel.

  • The theorem provides the theoretical foundation of channel coding. As long as the transmission rate does not exceed capacity, some coding method can in principle satisfy the desired reliability.

4. The Joint Source–Channel Coding Theorem

4.1 The joint theorem

  • Efficient and reliable transmission can be achieved through two independently designed stages: source coding and channel coding.

  • Source coding: remove redundancy so that the average information rate $R_s$ approaches the source entropy $H(S)$ and efficiency improves.

  • Channel coding: add redundancy so that the coded information rate $R$ does not exceed the channel capacity $C$, thereby improving reliability.

4.2 Shannon’s separation theorem, Theorem 6.7

  • For a source $S$, if its limiting entropy $H_\infty < C$, then source and channel codes exist for which the average error probability $P_E$ approaches zero.

  • Conclusion: provided that the source entropy $H(S)$ is below the channel capacity $C$, or $H(S) < C$, reliable communication can be achieved through two separate stages—source coding followed by channel coding.
