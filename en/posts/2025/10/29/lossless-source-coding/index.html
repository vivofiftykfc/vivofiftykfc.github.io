Information Theory, Chapter 5: The Lossless Source Coding Theorem

1. Introduction

1.1 Purposes and Categories of Coding

  • Source coding: coding intended to improve the efficiency of communication. By compressing the redundancy of the source, it reduces the average code rate.

  • Channel coding: coding intended to improve the reliability of information transmission. By adding redundancy to the source, it resists interference in the channel.

  • Cryptography: coding intended to improve the security of communication.

1.2 Theoretical Foundations of Source Coding

Source coding theory rests mainly on two theorems:

  1. The lossless source coding theorem, or Shannon’s first theorem: the foundation for coding discrete sources and digital signals.

  2. The rate-distortion source coding theorem: the foundation for coding continuous sources and analogue signals.

1.3 Encoder Model and Codeword Length

  • Encoder input: the original source alphabet $S={S_1, S_2, \ldots, S_q}$.

  • Channel alphabet, or code symbols: $X={x_1, x_2, \ldots, x_r}$.

  • Encoder output, or codewords: $C:{W_1, W_2, \ldots, W_q}$.

  • Codeword length $l_i$: the number of code symbols contained in the codeword $W_i$.

2. Fixed-Length Codes

2.1 Definition of a Fixed-Length Code

  • If all the codewords in a code have the same length, the code is called a fixed-length code.

  • Its codeword length is fixed.

2.2 The Required Codeword Length

  • If an $r$-ary code is used to encode $q$ source symbols at fixed length, its codeword length $l$ must satisfy:

    $$
    q \le r^l
    $$

  • If the $N$th extension of the source is encoded at fixed length, it must satisfy:

    $$
    q^N \le r^l
    $$

    • The average number of code symbols required per source symbol, $\frac{l}{N}$, must satisfy:
      $$
      \frac{l}{N} \ge \frac{\log_r q}{\log_r r}
      $$

This is easy to understand, so there is no need to elaborate further.

3. The Fixed-Length Source Coding Theorem

3.1 Central Idea

  • Through the $N$th extension of a source, its sequences are divided into a high-probability set $G$, whose members occur frequently, and a low-probability set $\bar{G}$, whose members occur infrequently.

  • Only the sequences in the high-probability set $G$ are encoded, while those in the low-probability set $\bar{G}$ are discarded. The required codeword length is thereby reduced, while the probability of a decoding error approaches zero.

3.2 Theorem 5.3: The Fixed-Length Source Coding Theorem

Consider a discrete memoryless source with entropy $H(S)$, denoted by $S$. Suppose that its $N$th extension is encoded with a fixed-length $r$-ary code of length $l$. For any $\epsilon > 0$:

  1. Nearly lossless coding is achievable provided that:

    $$
    \frac{l}{N} \ge \frac{H(S)+ \epsilon}{\log_2 r}
    $$

    As $N \to \infty$, the decoding error probability approaches 0.

  2. Lossless coding is impossible if:

    $$
    \frac{l}{N} < \frac{H(S)-2 \epsilon}{\log_2 r}
    $$

    As $N \to \infty$, the decoding error probability approaches 1.

Conclusion: $\frac{H(S)}{\log_2 r}$ gives the limiting average codeword length required for lossless fixed-length coding, measured as the number of code symbols needed for each source symbol.

4. Variable-Length Codes

4.1 Categories of Variable-Length Codes

  • Variable-length code: a code whose codeword lengths $l_i$ are not all the same.

  • Non-singular code: a code in which all codewords are distinct.

  • Uniquely decodable code, or UCD: a code in which every sequence of codewords can be translated uniquely into the corresponding sequence of source symbols.

  • Instantaneous code, or prefix code: a class of uniquely decodable codes in which no codeword is the prefix of another. A codeword can therefore be identified during decoding without reference to the codewords that follow it.

4.2 The Kraft Inequality: Theorems 5.4 and 5.5

  • If the code-symbol alphabet is $X={x_1, \ldots, x_r}$, any $r$-ary instantaneous code or uniquely decodable code whose codeword lengths are $l_i$ must satisfy the following inequality:

    $$
    \sum_{i=1}^{q} r^{-l_i} \le 1
    $$

  • Theorem 5.6: if a uniquely decodable code with codeword lengths $l_i$ exists, an instantaneous code with the same lengths must also exist. In terms of codeword length, therefore, a uniquely decodable code is no better than an instantaneous code, and it is enough to discuss instantaneous codes alone.

4.3 Testing Whether a Variable-Length Code Is Uniquely Decodable: The Sardinas–Patterson Test

  1. From all possible trailing suffixes of the codewords in the code $C$, form a set $F$.

  2. If and only if the set $F$ contains none of the codewords, the code $C$ is uniquely decodable.

5. The Variable-Length Source Coding Theorem

5.1 Compact Codes and Average Codeword Length

  • Average codeword length $\bar{L}$:

    $$
    \bar{L} = \sum_{i=1}^{q} P(S_i) l_i
    $$

  • Compact code, or optimal code: a uniquely decodable code with the smallest average codeword length $\bar{L}$. The fundamental problem of lossless source coding is to find such a compact code.

5.2 Theorem 5.8: The Lossless Variable-Length Source Coding Theorem, or Shannon’s First Theorem

A supplementary point: a compact code satisfies $R=\frac{H(S)}{\bar{L}}$.

For a discrete memoryless source $S$, consider its $N$th extension $S^N$, and let the code-symbol alphabet of the encoder be $X={x_1, \ldots, x_r}$. A uniquely decodable code can always be found such that, for each symbol in the source $S$, the required average codeword length $\bar{L} = \sum_{i=1}^q p_il_i$ satisfies:

$$
\frac{H(S)}{\log_2 r} \le \frac{\bar{L}}{N} < \frac{H(S)}{\log_2 r} + \frac{1}{N}
$$

As $N \to \infty$, the average codeword length can approach the limiting value $\frac{H(S)}{\log_2 r}$.

  • Central conclusion: the source entropy $H(S)$ is the limiting value for lossless source coding. To achieve lossless coding, the average number of code symbols required for each source symbol is the $r$-ary entropy of the source, $H_r(S) = \frac{H(S)}{\log_2 r}$.

5.3 Physical Meaning and Coding Efficiency

  • Essence: lossless source coding transforms a source so that the new source of code symbols—the input source of the channel—approaches an equiprobable distribution. The information transmission rate $R$ of the channel can thus approach the channel capacity $C$, leading to an ideal statistical match between source and channel.

  • Coding efficiency $\eta$: a measure of the effect of coding.

    $$
    \eta = \frac{H(S)}{\bar{L} \log_2 r}
    $$

    When $\bar{L}$ reaches the limiting value $\frac{H(S)}{\log_2 r}$, the optimal coding efficiency is $\eta_{\max} = 1$.
