Chapter 2 — Random Processes: Time-Domain Analysis

1 Basic Concepts and Statistical Characteristics of Random Processes

1.1 Basic Concepts of a Random Process

A random process $X(t,s)$ can be understood from both macroscopic and microscopic perspectives:

Perspective Description Fixed quantity Variable quantity Result
Macroscopic view (a family of time functions) A mapping from the sample space to a function space None Both $t$ and $s$ vary Random process
Sample function One realisation of a random process $s$ is fixed $t$ varies Known time function
Microscopic view (a time-varying random variable) At every specified time $t_i$, it is a random variable $t$ is fixed $s$ varies Random variable
Deterministic value Both the sample point and time are fixed Both $t$ and $s$ are fixed None Deterministic value

Definition 1 (family of time functions/macroscopic view):

Let the sample space of a random experiment be $S={s_i}$. For every sample $s_i \in S$, there is a corresponding time function $X(t,s_i)$, where $t \in T$. All samples in $S={s_i}$ therefore correspond to a family of time functions ${X(t,s_i), s_i \in S}$. The mapping from the sample space to this function space is called a random process.

Definition 2 (time-varying random variable/microscopic view):

For every specified time $t_i$, if $X(t_i,s)$ is a random variable, then $X(t,s)$ is called a random process.

This idea has already become fairly clear in the course on communication principles, so I will not go into it again.

1.2 Classification of Random Processes

I. Classification by whether time and amplitude (state) are continuous or discrete

  • Continuous random process: continuous in time and continuous in state.
  • Discrete random process: continuous in time and discrete in state.
  • Continuous random sequence: discrete in time and continuous in state.
  • Discrete random sequence: discrete in both time and state.

A pile of empty distinctions. No need to spend much time on them.

II. Classification by the properties of sample functions

  • Uncertain (unpredictable) random process

  • Deterministic (predictable) random process: for example, the random-phase signal $A\sin(\omega t+\Phi), \Phi \sim U(0,2\pi)$.

III. Classification by the characteristics of probability distributions

  • Stationary random process: a process whose statistical characteristics do not vary with time, such as thermal noise.
  • Normal random process
  • Markov random process
  • Independent-increment process
  • Independent random process

There is no need to inspect every category in detail. It is enough to know that these classifications exist; for now, they are not particularly useful.

1.3 Probability Distributions of Random Processes

The “certainty” contained in randomness means that the overall properties of a random process can be described by statistical averages, including moments, characteristic functions, and probability distribution or density functions.

I. One-Dimensional Probability Distribution

  • One-dimensional distribution function: $F_X(x;t) = P{X(t) \le x}$, which is a deterministic function.

  • One-dimensional probability density: $f_X(x;t) = \frac{\partial F_X(x;t)}{\partial x}$, which may be a time-varying probability density.

II. Two-Dimensional Probability Distribution

  • Two-dimensional distribution function: $F_{X_1X_2}(x_1,x_2;t_1,t_2) = P{X(t_1) \le x_1, X(t_2) \le x_2}$.

  • Two-dimensional probability density: $f_{X_1X_2}(x_1,x_2;t_1,t_2) = \frac{\partial^2 F_{X_1X_2}(x_1,x_2;t_1,t_2)}{\partial x_1 \partial x_2}$.

III. Obtaining a Probability Density through a Transformation of Random Variables

  • Monotonic invertible transformation: $Y = g(X), X = h(Y)$

    $$f_Y(y) = f_X[x=h(y)] \left| \frac{dh(y)}{dy} \right| = f_X(x) \left| \frac{dg(x)}{dx} \right|^{-1} \Big|_{x=h(y)}$$

  • Non-monotonic invertible transformation: $Y = g(X)$, with multiple roots $X_k = h_k(Y)$

    $$f_Y(y) = \sum_{k} f_X[x=h_k(y)] \left| \frac{dh_k(y)}{dy} \right|$$

  • Two-dimensional transformation (Jacobian determinant): $Y_1=g_1(X_1,X_2), Y_2=g_2(X_1,X_2)$

    $$f_{Y_1Y_2}(y_1,y_2) = \left| J_h(y_1,y_2) \right| f_{X_1X_2}[x_1=h_1(y_1,y_2), x_2=h_2(y_1,y_2)]$$

    Here, $|J_h|$ is the absolute value of the determinant formed by the partial derivatives of $X_1, X_2$ with respect to $Y_1, Y_2$.

Chapter 1 already covered most of this material, so there is no reason to repeat it in detail.

1.4 Numerical Characteristics of Random Processes

  • Mean function $m_X(t) = E[X(t)]$

Note: this is also called the second-order raw moment.

  • Variance function $D_X(t) = E{[X(t)-m_X(t)]^2}$

Note: this is also called the second-order central moment.

  • Autocorrelation function $R_X(t_1, t_2) = E[X(t_1)X(t_2)]$

  • Covariance function $K_X(t_1, t_2) = R_X(t_1, t_2) - m_X(t_1)m_X(t_2)$

2 Differentiation and Integration of Random Processes

2.0 Preliminary Concept: Mean-Square Limit

  • Second-order process: a random process satisfying $\forall t \in T, E[X^2(t)] < \infty$.

  • Mean-square limit (l.i.m.): A sequence of random variables ${X_n}$ is said to converge to $X$ in the mean-square sense, written as $\underset{n\rightarrow\infty}{\mathrm{l.i.m.}} X_n = X$, if:

    $$\lim_{n\rightarrow\infty} E|X_n - X|^2 = 0$$

Here, l.i.m. is short for “limit in mean square”.

Mean-square convergence is defined because it differs from ordinary convergence: what must converge is the mean square, not every individual sample point.

Of course, when it comes to solving exercises, we still end up using much the same machinery as in ordinary calculus.

Properties of the Mean-Square Limit

$$\underset{n \to \infty}{\text{l.i.m}} c_n = \lim_{n \to \infty} c_n = c$$

$$\underset{n \to \infty}{\text{l.i.m}} Z = Z $$

$$\underset{n \to \infty}{\text{l.i.m}} c_n Z = cZ$$

  • Algebraic properties: The order of a mean-square limit may be exchanged with addition, multiplication by a constant, and expectation ($E$).

    $$\underset{n \to \infty}{\text{l.i.m}} (aX_n + bY_n) = aX + bY$$

    $$\lim_{n\rightarrow\infty} E X_n = E X = E \left[ \lim_{n\rightarrow\infty} X_n \right]$$

  • Criterion for mean-square convergence (Cauchy criterion): A necessary and sufficient condition for ${X_n}$ to converge in the mean-square sense is:

    $$\lim_{n,m\rightarrow\infty} E|X_m - X_n|^2 = 0$$

2.1 Stochastic Continuity: Mean-Square Continuity

  • Definition: $X(t)$ is said to be mean-square continuous at time $t_0$ if:

    $$\lim_{\Delta t\rightarrow0} E{[X(t_0+\Delta t)-X(t_0)]^2} = 0$$

  • Criterion for mean-square continuity (necessary and sufficient condition):

    A second-order process $X(t)$ is mean-square continuous at $t_0$ if and only if its correlation function $R(s,t)$ is continuous at $(t_0, t_0)$.

    In other words, the mean-square continuity of a second-order process can be determined through the ordinary continuity of its correlation function.

  • Properties:

    • If $X(t)$ is mean-square continuous at $t_0$, its mean function $m_X(t)$ and variance function $D_X(t)$ are also continuous at $t_0$.

    • The order of “E” and “l.i.m.” may be exchanged.

2.2 Differentiation of a Random Process (Mean-Square Differentiability)

  • Criterion for mean-square differentiability (necessary and sufficient condition):

    A second-order process $X(t)$ is mean-square differentiable at $t_0$ if and only if its correlation function $R(s,t)$ possesses a generalised second derivative at $(t_0, t_0)$. In plain terms, when the two independent variables of the correlation function are equal, a continuous second-order mixed partial derivative must exist.

  • Properties of the mean-square derivative:

    • If $X(t)$ is mean-square differentiable at $t$, then $X(t)$ is mean-square continuous at $t$.

    • The order of “E” and “$\frac{d(\cdot)}{dt}$” may be exchanged. That is, $E[\frac{d}{dt}X(t)] = \frac{d}{dt}E[X(t)]$.

2.3 Integration of a Random Process (Mean-Square Integrability)

  • Sufficient conditions for mean-square integrability:

    • For a second-order process $X(t)$, if the double integral of its correlation function $R(s,t)$ exists and is finite, then $X(t)$ is mean-square integrable on $[a,b]$.

    • If $X(t)$ is mean-square continuous on $[a,b]$, then $X(t)$ is mean-square integrable on $[a,b]$.

  • Property of the mean-square integral:

    • The order of “E” and mean-square integration may be exchanged. That is, $E[\int_a^b X(t)dt] = \int_a^b E[X(t)]dt$.

3 Stationary and Ergodic Random Processes

3.1 Stationary Random Processes

  • Stationary random process: a random process whose statistical characteristics do not change as time passes.

  • Such processes are divided into strict-sense stationary (SSS) and wide-sense stationary (WSS) processes.

I. Strict-Sense Stationary Random Process (SSS)

  • Definition: For a random process $X(t)$, every $n$-dimensional probability distribution function $F_X(x_1,\dots,x_n; t_1,\dots,t_n)$ remains unchanged under a translation in time. It is therefore independent of the starting point in time and depends only on the time differences $\tau_k=t_k-t_1$.

    $$F_X(x_1,\dots,x_n; t_1,\dots,t_n) = F_X(x_1,\dots,x_n; t_1+\tau,\dots,t_n+\tau)$$

  • Properties of lower-order moments:

    • The mean function $m_X(t)$ is independent of time $t$ and is therefore a constant.

    • The autocorrelation function $R_X(t_1, t_2)$ depends only on the time difference $\tau=t_2-t_1$, and can thus be written as $R_X(\tau)$.

This condition is plainly too demanding to be satisfied in most cases, and its range of application is therefore rather narrow. We consequently need wide-sense stationarity to do the practical work.

II. Wide-Sense Stationary Random Process (WSS)

  • Definition (Khinchin): A random process $X(t)$ must satisfy the following conditions:

    1. Its mean function $m_X(t)$ is independent of time $t$ and is therefore a constant $m_X$.

    2. Its autocorrelation function $R_X(t_1, t_2)$ depends only on the time difference $\tau=t_2-t_1$, and may therefore be written as $R_X(\tau)$.

  • Relationship:

    • Strict-sense stationarity $\implies$ wide-sense stationarity, but the reverse does not hold, except for a normal process.

3.3 Ergodic Processes (Ergodicity)

The point is to replace a statistical average with a time average.

  • Basic idea: The statistical average, taken over a family of samples, is equal to the time average taken over a single sample function.

    • Time averages: the time mean $\overline{X}$ and the time correlation function $\mathfrak{R}_X(\tau)$.

  • Definition of a wide-sense ergodic process: Suppose the random process $X(t)$ is wide-sense stationary and is ergodic in both its mean and autocorrelation function. It is then defined as a wide-sense ergodic process.

    1. Mean ergodicity: The time mean converges in the mean-square sense to the statistical mean.

      $$\overline{X} = \lim_{T\rightarrow\infty} \frac{1}{2T} \int_{-T}^{T} X(t)dt \xrightarrow{\mathrm{m.s.}} E[X(t)]$$

    2. Autocorrelation ergodicity: The time autocorrelation function converges in the mean-square sense to the statistical autocorrelation function.

      $$\mathfrak{R}X(\tau) = \lim{T\rightarrow\infty} \frac{1}{2T} \int_{-T}^{T} X(t)X(t+\tau)dt \xrightarrow{\mathrm{m.s.}} R_X(\tau)$$

In practice, as soon as a stationary signal turns up, we simply use these averages without worrying too much about the fine print. Reckless, perhaps, but that is how the exercises tend to go.

4 Joint Probability Distributions and Cross-Correlation Functions of Random Processes

4.1 Joint Probability Distribution of Two Random Processes

Consider two random processes $X(t)$ and $Y(t)$.

  • $(n+m)$-dimensional joint distribution function:

    $$F_{XY}(x_1,\dots,x_n;y_1,\dots,y_m;t_1,\dots,t_n;t_1’,\dots,t_m’) = P{X(t_1) \le x_1,\dots, X(t_n) \le x_n; Y(t_1’) \le y_1,\dots, Y(t_m’) \le y_m}$$

  • $(n+m)$-dimensional joint probability density:

    $$f_{XY}(\dots) = \frac{\partial^{n+m}F_{XY}(\dots)}{\partial x_1 \dots \partial x_n \partial y_1 \dots \partial y_m}$$

  • Points to note:

    1. If the $n+m$-dimensional joint probability distribution of the two processes is given, all their statistical characteristics are determined.

    2. Their lower-dimensional joint probability distributions can be derived from the higher-dimensional distribution.

There is not much else to say. This is simply a generalisation of what was already established above.

4.2 Cross-Correlation Function

  • Definition of the cross-correlation function: It describes the statistical association between the states of two random processes at different times.

    $$R_{XY}(t_1, t_2) = E[X(t_1)Y(t_2)] = \int_{-\infty}^{\infty}\int_{-\infty}^{\infty}xyf_{XY}(x,y;t_1,t_2)dxdy$$

  • Cross-covariance function (centred cross-correlation function):
    $$K_{XY}(t_1, t_2) = E{[X(t_1)-m_X(t_1)][Y(t_2)-m_Y(t_2)]}$$
    $$K_{XY}(t_1, t_2) = R_{XY}(t_1, t_2) - m_X(t_1)m_Y(t_2)$$

Joint Stationarity

  • Joint strict-sense stationarity: The joint probability distribution of $X(t)$ and $Y(t)$ remains unchanged under a translation in time.

  • Joint wide-sense stationarity (wide-sense stationary dependence):

    1. Both $X(t)$ and $Y(t)$ are wide-sense stationary.

    2. The cross-correlation function $R_{XY}(t, t+\tau)=R_{XY}(\tau)$ depends only on the time difference $\tau$.

  • Joint wide-sense ergodicity:

    1. $X(t)$ and $Y(t)$ are jointly wide-sense stationary.

    2. The time cross-correlation function converges in the mean-square sense to the statistical cross-correlation function.

      $$\mathfrak{R}{XY}(\tau) = \underset{T\rightarrow\infty}{\mathrm{l.i.m.}} \frac{1}{2T}\int{-T}^{T}X(t)Y(t+\tau)dt = R_{XY}(\tau)$$

5 Complex Random Processes

  • Complex random signal: $Z(t) = X_c(t) + jX_s(t)$.

The difference between its calculation and that for a real random process is much the same as the difference between complex and real numbers, so there is no need to elaborate here.

  • Wide-sense stationary complex random process:

    1. The mean function $m_Z(t) = E[Z(t)]$ is a constant.

    2. The autocorrelation function $R_Z(t_1, t_2) = E[Z(t_1)Z^*(t_2)]$ depends only on the time difference $\tau=t_2-t_1$, and can therefore be written as $R_Z(\tau)$.

  • Jointly wide-sense stationary complex random processes:

    1. $Z_1(t)$ and $Z_2(t)$ are each wide-sense stationary.

    2. The cross-correlation function $R_{Z_1Z_2}(t, t+\tau) = E[Z_1(t)Z_2^*(t+\tau)]$ depends only on $\tau$.

[!NOTE]
As can be seen, the distinction is much the same as that between real and complex numbers. There is no need to inspect it too closely.

6 Discrete-Time Random Processes

  • Representation: $X(nT)$ or $X(n)$.

  • Method of analysis: In essence, it is the same as the analysis of a continuous-time random signal.

  • Correspondence: the time variable $t \rightarrow n$.

[!NOTE]
As can be seen, there is almost no essential difference from the continuous-time case, so there is no need to inspect it too closely.

7 Normal Random Processes

  • Principal properties:

    1. The $n$-dimensional probability density of a normal random process is completely determined by the collection of its means and the collection of its covariance functions.

    2. For a normal process, strict-sense stationarity and wide-sense stationarity are equivalent.

    3. For a normal process, being uncorrelated is equivalent to being independent.

    4. The output produced when a normal random process passes through a linear system remains a normal process.
