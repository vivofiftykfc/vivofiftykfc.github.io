Chapter 1 — Foundations of Probability Theory

Here begins the main text.

1.1 Basic Concepts

  • Random Experiment: an experiment whose outcome cannot be predicted in advance, but which can be repeated.

  • Sample Space $\Omega$: the set of all possible outcomes.

  • Random Event $A \subseteq \Omega$:

    • An elementary event contains only one outcome;

    • A compound event contains several outcomes;

    • $\Omega$ is the certain event, whereas $\varnothing$ is the impossible event.

  • Probability (axiomatic definition)

    1. $0 \le P(A) \le 1$

    2. $P(\Omega) = 1$

    3. If $A \cap B = \varnothing$, then $P(A \cup B) = P(A) + P(B)$

Note: classical probability, geometric probability, frequentist probability, and axiomatic probability merely offer different ways of understanding the same subject. This course adopts the axiomatic definition together with a formal treatment based on density functions.

1.2 One-Dimensional Random Variables

Definition

A random variable $X(\omega)$ is a function that maps the sample space to the real-number domain.

Distribution Function

$$F_X(x) = P{X \le x}$$

It has the following properties:

  1. It is monotonically non-decreasing;
  2. It is right-continuous;
  3. $\lim_{x\to -\infty}F=0$, and $\lim_{x\to +\infty}F=1$.

Discrete and Continuous Types

Type Description Representation
Discrete $P{X=x_k}=p_k$ Probability mass function (PMF)
Continuous $P{x<X<x+dx}=f(x)dx$ Probability density function (PDF)

The PDF of a discrete random variable can also be expressed in a unified form through the Dirac delta function:

$$f(x) = \sum_k p_k \delta(x - x_k)$$

Transformations of Random Variables

Suppose $Y = g(X)$.

  • If the transformation is monotonic and invertible:

$$f_Y(y) = f_X(x) \left| \frac{dx}{dy} \right|$$

The concrete derivation can be understood as follows:

Look at the diagram. If the distribution of (y) is required, the ratio between $\Delta y$ and $\Delta x$ can be used directly; it gives the corresponding ratio between (y) and (x) in the calculation.

  • If the transformation is invertible but non-monotonic, sum the contributions from its multiple solutions.

Common examples include $Y = \sin X$ and $Y = X^2$.

1.3 Multidimensional Random Variables

Joint Distribution Function

$$F_{XY}(x,y) = P{X \le x, Y \le y}$$

Joint Density Function

$$f_{XY}(x,y) = \frac{\partial^2 F_{XY}}{\partial x \partial y}$$

Marginal Distribution

A marginal distribution is obtained by setting aside one factor and considering only the other.

$$f_X(x) = \int_{-\infty}^{+\infty} f_{XY}(x,y) , dy$$

Conditional Density

$$f_{Y|X}(y|x) = \frac{f_{XY}(x,y)}{f_X(x)}$$

If $f_{XY}(x,y) = f_X(x)f_Y(y)$, the variables are said to be independent.

Transformation of Two-Dimensional Random Variables (Jacobian)

Suppose

$$
Y_1 = g_1(X_1,X_2), \quad Y_2 = g_2(X_1,X_2)
$$

Then

$$
f_{Y_1Y_2}(y_1,y_2) = f_{X_1X_2}(x_1,x_2) \cdot \left| J_g^{-1} \right|
$$

1.4 Numerical Characteristics

One-Dimensional Case

Quantity Discrete Continuous
Expectation $E[X]=\sum x_k p_k$ $E[X]=\int xf(x)dx$
Variance $D[X]=E[X^2]-E[X]^2$ Same as on the left

Two-Dimensional Case

  • Covariance

$$\mathrm{cov}(X,Y) = E[XY] - E[X]E[Y]$$

  • Correlation Coefficient

$$\rho_{XY} = \frac{\mathrm{cov}(X,Y)}{\sqrt{D[X]D[Y]}}$$

  • Property: $\rho \in [-1,1]$. The greater $|\rho|$ is, the stronger the linear correlation becomes.

1.5 Characteristic Function

$$\phi_X(u) = E[e^{juX}]$$

  • It is equivalent to the Fourier transform of $f_X(x)$;
  • It can be used to derive convolution results and prove limit theorems;
  • The characteristic function of a Gaussian distribution remains Gaussian in form.

1.4 Numerical Characteristics of Random Variables

One-Dimensional Random Variables

Quantity Discrete Continuous
Expectation $E[X]=\sum x_k p_k$ $E[X]=\int xf(x)dx$
Variance $D[X]=E[X^2]-E[X]^2$ Same as on the left
Raw moment $\mu_k=E[X^k]$ Same as on the left
Absolute moment $\lambda_k=E[|X|^k]$ Same as on the left
Central moment $v_k=E[(X-E[X])^k]$ Same as on the left
Standardised moment $\tilde{v}_k=E\left[\left(\frac{X-\mu_X}{\sigma_X}\right)^k\right]=\frac{v_k}{\sigma_X^k}$ Same as on the left

Properties of Numerical Characteristics

  1. Expectation of a function: $E[g(\xi)]=\int g(x)f(x)dx$

    • Linearity: $E[a\xi+b]=aE[\xi]+b$

    • Variance: $D[a\xi+b]=a^2D[\xi]$

  2. Relationship between central and raw moments:

$$v_n=\sum_{k=0}^n(-1)^{n-k}C_n^k\mu_1^{n-k}\mu_k$$

  1. Minimum-variance property: $E[(\xi-E[\xi])^2]\leq E[(\xi-x)^2]$

Two-Dimensional Random Variables

Quantity Discrete Continuous
Joint raw moment $E[X^jY^k]=\sum\sum x_m^j y_n^k p_{m,n}$ $E[X^jY^k]=\iint x^j y^k f(x,y)dxdy$
Joint central moment $E[(X-E[X])^j(Y-E[Y])^k]$ Same as on the left
Correlation $R_{XY}=E[XY]$ Same as on the left
Covariance $K_{XY}=E[XY]-E[X]E[Y]$ Same as on the left
Correlation coefficient $r_{XY}=\frac{K_{XY}}{\sigma_X\sigma_Y}$ Same as on the left

Important Concepts

  • Covariance matrix:

$$\Sigma=\begin{bmatrix}K_{XX} & K_{XY}\ K_{YX} & K_{YY}\end{bmatrix}$$

  • Uncorrelated variables: $r_{XY}=0 \Leftrightarrow K_{XY}=0 \Leftrightarrow E[XY]=E[X]E[Y]$

Independence implies an absence of correlation, but the reverse is not necessarily true. Correlation describes only the degree of linear association between two random variables, whereas independence is a stronger condition. For a joint normal distribution, however, being uncorrelated is equivalent to being statistically independent.

  • Orthogonality: $E[XY]=0$. If either (X) or (Y) has a mean of zero, the absence of correlation is equivalent to orthogonality.

Linear Minimum Mean-Square Estimation

  • Optimal linear estimate: $\hat{Y}=E[Y]+\frac{K(X,Y)}{D(X)}(X-E[X])$

  • Minimum mean-square error: $\min e=(1-r_{XY}^2)D(Y)$

1.5 Characteristic Functions of Random Variables

Definition

In effect, this is simply a Fourier transform.

$$C(u)=E[e^{juX}]=\int_{-\infty}^{\infty}e^{jux}f(x)dx$$

Properties

  1. Boundedness: $|C(u)|\leq C(0)=1$

  2. Conjugate symmetry: $C(-u)=\overline{C(u)}$

  3. Linear transformation: if $Y=aX+b$, then $C_Y(u)=e^{jub}C_X(au)$

  4. Moment generation: $E[X^k]=j^{-k}C^{(k)}(0)$

  5. Independence: if $X,Y$ are independent, then $C_{X+Y}(u)=C_X(u)C_Y(u)$

Characteristic Function of a Gaussian Distribution

  • The characteristic function of $X\sim N(a,\sigma^2)$ is:

$$C_X(u)=\exp\left(jau-\frac{\sigma^2 u^2}{2}\right)$$

  • A linear transformation of a Gaussian random variable remains Gaussian.

  • In the multidimensional case, if $X\sim N(m_X,K_X)$, then $Y=AX+b\sim N(Am_X+b,AK_XA^T)$.
