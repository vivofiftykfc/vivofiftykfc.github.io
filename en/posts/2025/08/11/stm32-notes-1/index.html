Introduction

  • STM32 is a family of 32-bit microcontrollers developed by ST around ARM Cortex-M cores. Its many applications need not be listed here.
  • ARM can refer either to the company or to an ARM processor core.
  • ARM designs the core; semiconductor manufacturers complete the surrounding circuits and manufacture the chips.

These notes follow Jiangxie’s course and use the STM32F103C8T6.


  • Core: ARM Cortex-M3
  • Clock frequency: 72 MHz
  • RAM (Random Access Memory): 20K SRAM
  • ROM (Read-Only Memory): 64K Flash
  • Supply voltage: 2.0–3.6 V, normally 3.3 V
  • Package: LQFP48

Data Types

The data types take the following forms. A careful look at the table is enough.

Macros

#define ABC 123 gives a readable name to a number.

typedef unsigned char uint8_t follows a similar idea: it replaces a long type name with a shorter one that is easier to use.

Enumerations

  • Keyword: enum

  • Purpose: define an integer variable whose possible values are restricted; in effect, a collection of named constants.

  • Defining an enumeration variable:

    enum{FALSE = 0, TRUE = 1} EnumName;

    Because enumeration type names may be long, typedef is normally used to rename them.

  • Referring to its members:

    EnumName = FALSE;

    EnumName = TRUE;

Basic Knowledge

A GPIO pin can be configured in eight input and output modes:

See page 110 of the reference manual for details.

Pin voltage ranges from 0 V to 3.3 V, although some pins tolerate 5 V.

In output mode, a port can produce high or low levels to drive an LED, control a buzzer, or generate the timing of a simulated communication protocol.

In input mode, it can read a level or voltage from a button or external module, collect a voltage through the ADC, or receive data through a simulated protocol.

Experiments

Components

  • Active buzzer: contains an oscillator and sounds continuously when DC voltage is applied; its frequency is fixed.
  • Passive buzzer: contains no oscillator and requires pulses from the controller. Changing the pulse frequency changes the sound.
  • LED: omitted.
  • Button: a mechanical spring contact opens and closes the circuit and therefore bounces; debouncing is required.
  • Sensor module: a photoresistor, thermistor, infrared receiver, or similar element changes resistance with an external analogue quantity. A divider with a fixed resistor produces an analogue voltage, which a comparator can convert into a binary digital level.

Coding Procedure

  • Configure the clock through RCC.
  • Initialize GPIO.
  • Implement the program logic in the main loop.
